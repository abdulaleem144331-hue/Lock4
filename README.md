# LOCK//4 Final v6
Native Android focus blocker for a 120-day NEET lock-in.

Features: timed 50-minute/custom sessions, persistent session state, configurable blocked apps, AccessibilityService foreground interception, full-screen block overlay, local-only operation.

## Free APK build
Install Android Studio, open this project, let Gradle sync/download SDK 35, then Build > Build APK(s). Android Studio will show the APK path. Transfer the APK to your phone and install it. Open LOCK//4, enable its Accessibility Service in Android Settings, select apps, and start Lock-In.

The Accessibility permission is explicit and user-controlled. This is a self-control tool, not covert monitoring.
